# Convite Theo 2 anos

Site do convite: `/theo-2-anos/`
Painel privado: `/theo-2-anos/admin.html`

## Para ativar as confirmações reais
1. Criar um projeto gratuito no Supabase.
2. Rodar `supabase-setup.sql` no SQL Editor.
3. Em Authentication, desativar novos cadastros públicos e criar apenas o usuário administrador.
4. Copiar Project URL e anon public key para `config.js`.
5. Enviar as fotos do Theo com os nomes:
   - assets/theo-1.jpg
   - assets/theo-2.jpg
   - assets/theo-3.jpg
   - assets/theo-4.jpg
   - assets/theo-5.jpg

O site registra nome, resposta, quantidade de adultos/crianças, observação, total de acessos e último acesso por aparelho.
